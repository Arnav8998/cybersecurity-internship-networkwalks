# Week 1 – Wireshark SOC Investigations

## Project Overview

This project documents six network traffic investigation labs undertaken as part of the Networkwalks Cybersecurity Internship.

The exercises focus on developing Security Operations Centre (SOC) skills through packet analysis, TCP stream reconstruction, suspicious activity detection and investigation of network communications.

## Objectives

- Identify suspicious source IP addresses.
- Analyse network packets and TCP conversations.
- Investigate unencrypted HTTP communications.
- Recognise possible brute-force authentication attempts.
- Examine suspicious voice communications.
- Document findings using supporting network evidence.

## Investigation Methodology

1. Examine the supplied network traffic.
2. Identify the protocols and communications relevant to the task.
3. Apply appropriate packet filters or stream analysis techniques.
4. Investigate suspicious activity.
5. Record findings supported by the observed evidence.
6. Explain the security implications.

## Evidence and Findings

Investigation screenshots, relevant packet observations and findings will be organised in separate folders for each lab.

Only sanitised evidence will be published. Credentials, sensitive identifiers and other confidential information will be redacted where necessary.
