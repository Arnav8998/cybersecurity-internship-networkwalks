# Week 1 – Kali Linux Lab Setup

## Objective
Configure a Kali Linux cybersecurity testing environment with static IPv4 addressing.

## Environment
- Kali Linux
- Azure Lab Services
- NetworkManager (nmcli)

## Implementation
1. Investigated software installation restrictions.
2. Accessed a university-provided Azure Kali Linux environment.
3. Configured static IP address 10.0.0.2/24.
4. Verified the configuration using ip addr show eth0.

## Results
Successfully assigned and verified 10.0.0.2/24 on eth0.
